审查基线为 v6.7.0（e5201c3），工作区无既有未提交改动。审查沿 `main::real_main` 的 CLI 入口、子网与内环计划/执行器、接收端速率判定、agent 作业与资源回收、控制台鉴权/并发、历史文件访问、报告/图表/Excel，以及 Vue 配置/轮询/结果状态和发布工作流展开。结合既有结构断言与全量测试检查兼容面；本次没有调整 Windows 内置灌包参数、判定优先级或 RX 验收规则。

## 已确认并修复的问题

1. 内环 RESUME 有效期被跳过记录续期：`resumed_row` 保存 `verdict=PASS, resumed=true`，而 `history::fresh_pass_ids` 原先只查 PASS，并以新文件修改时间计算 24 小时。重复跳过可使原始证据过期后仍被复用。现在仅接受实测 PASS；旧记录缺少 `resumed` 时保留兼容，非法类型不能成为证据。回归覆盖实测、旧记录、跳过、失败、过期和原始证据删除。
2. 并发启动监控突破上限：会话数检查与登记之间释放锁，多个 HTTP worker 可共同占用同一空槽。现在检查、创建线程与登记持有同一次会话表锁；网络请求与采样仍在线程内执行。回归预填 7 个槽位，让 16 个线程同时争用最后一格，并验证仅一个成功。

两项回归均在旧逻辑下实际失败：历史扫描错误返回跳过与非法记录；监控旧实现允许 10 个请求争用唯一空槽。修复后通过。操作说明、Windows 快速开始、架构约束及自带文档包同步。
