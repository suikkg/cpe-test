# 子网与内环流程、功能联检

两种模式采用连接、计划、执行与共用历史入口。内环实际传输仍为电脑与 CPE 板侧，TCP/UDP 使用板侧 iperf3；其流量配置与门限独立于 Windows 双机基线。

| 功能 | 实现与联检 |
|---|---|
| 连接与选口 | 完整网卡表、搜索、扫描身份保护；未引用辅测机不阻断本机；子网提供明确一对本机接口的快捷测试并可恢复原计划 |
| 计划组织 | 链路集合、动态整集合、明确子集、共享流量配置、套件任务、分配与顺序；未分配网口不进入执行门禁 |
| 参数与门限 | TCP/UDP 多轴参数、独立窗口、时长与流数范围对齐；任务/协议/网口门限继承；工具口径独立；默认和任务 Ping 参数及 RTT 分档 |
| 轮次 | 外层整计划轮次；旧统一参数启用套件时保留单项重复；稳定身份和旧 RESUME 兼容 |
| 执行 | 预览哈希、启动令牌与未知状态、运行锁、定向跳过、停止、下一轮准备；任何未确认回收阻断后续起流 |
| 诊断 | 临时 TCP/UDP 覆盖、正流量事件后的负载时延、能力检查后的 IPv4 DF 探测、共用上限规则的 UDP 裁剪；均不改写 RX 验收 |
| 结果 | 接收端 RX 曲线、方向和工具明细、Ping 丢包/RTT、截图、阶段状态；生产页面只保留配置、状态和测量信息 |
| Excel | 概览、单元结果、方向明细、Ping 明细、异常单元、网口汇总；数字与空值语义、过滤与冻结、日志长度上限 |
| 历史 | 搜索、HTML/Excel/整轮包下载、配置恢复与 RESUME、两轮对比（共用 5% 速率变化门槛）；复用、跳过、缺失及无法唯一匹配分别展示 |

验收使用纯函数与生命周期测试、真实 HTTP 层的 Chromium 回归、前端产物闸门、Rust 全量测试与原生/Windows 目标 Clippy。网卡及启动由请求桩控制的浏览器回归不代表真实 Windows/CPE 流量验收。

当前 Windows 原生编译、单机快捷测试和 CPE 内环实流量证据见 [2026-10-14 验收记录](../docs/testing/windows-inner-subnet-parity-2026-10-14.md)，包括 ADB 控制通道的接线范围、真实 Ping 解析修复及导出独立核对。
